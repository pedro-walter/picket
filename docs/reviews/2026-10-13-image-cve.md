## traefik:v3.7 (registry, soul-spike, monitoria-soul-spike) — 12 findings (4 per agent)

`usr/local/bin/traefik`: stdlib v1.26.8 (CVE-2026-78667 Range DoS, CVE-2026-97031 ECH DoS, CVE-2026-78669 HTTP/2
SETTINGS flood) and golang.org/x/net v0.58.0 (CVE-2026-78669). Fixed in Go 1.26.9 / x/net 0.60.0.

`v3.7` is rolling and was rebuilt 2026-10-08 (v3.7.14), yet still ships Go 1.26.8. Go 1.26.9 only appeared on Docker Hub
2026-10-10, and traefik's newest tag v3.7.14 pins x/net v0.59.0 (go.mod), so **no published traefik image has the fix**.
A compiled Go binary can't be patched by an apk/apt overlay, so category B does not apply. Wait for v3.7.15 and re-pull.

Honest caveat: traefik is the edge proxy, so net/http and HTTP/2 are on its reachable path. These are availability-only
DoS issues, and this is a "no fix exists yet" suppression, not a reachability argument. A short expiry is deliberate.
Suppressing is optional; leaving them open is also defensible.

```sh
for c in CVE-2026-78667 CVE-2026-97031 CVE-2026-78669; do
picketctl rules add --kind image-cve --subject traefik --identifier "$c|stdlib" --cve $c \
  --reason "No traefik image ships Go >= 1.26.9 as of 2026-10-13 (v3.7.14 rebuilt 2026-10-08 still has stdlib 1.26.8; Go 1.26.9 released 2026-10-10). DoS only; re-pull when v3.7.15 lands." \
  --expires 2027-01-11 --inherit none
done
picketctl rules add --kind image-cve --subject traefik --identifier 'CVE-2026-78669|golang.org/x/net' --cve CVE-2026-78669 \
  --reason "No traefik image ships x/net >= 0.60.0 as of 2026-10-13 (v3.7.14 pins 0.59.0). HTTP/2 SETTINGS flood DoS; re-pull when a newer release lands." \
  --expires 2027-01-11 --inherit none
```
